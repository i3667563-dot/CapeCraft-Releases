# CapeCraft

Кастомные анимированные плащи для Minecraft 1.21.10 (Fabric). Поддержка PNG, APNG, GIF и WebP — включая полную анимацию с прозрачностью и бесконечным циклом.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/) для Minecraft **1.21.10**
2. Скопируй `capecraft-0.1.0.jar` из [Releases](https://github.com/i3667563-dot/CapeCraft-Releases/releases) в папку `mods/`
3. Запусти игру — мод загрузится автоматически

**Требования:** Fabric API, Fabric Language Kotlin (оба входят в стандартные сборки Fabric).

## Конфигурация

При первом запуске создаётся `config/capecraft.crn`. Формат — [Cren](https://github.com/i3667563-dot/CapeCraft), минималистичный и читаемый.

### Провайдеры

Провайдеры — источники плащей. Проверяются по порядку: первый успешный отдаёт плащ.

```
capeCraft {
    providers [
        # Прямая ссылка на картинку
        { name = "example", type = "url", url = "https://example.com/capes/{username}.png" }

        # JSON-API: извлекаем URL из ответа по пути
        { name = "api", type = "json", url = "https://api.example.com/cape?u={username}", extract = "$.data.cape_url" }

        # Локальный файл
        { name = "local", type = "file", path = "{root}/capes/{uuid}.png" }
    ]
}
```

### Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `{username}` | Имя профиля игрока |
| `{uuid}` | UUID без дефисов (нижний регистр) |
| `{name}` | Имя провайдера |
| `{root}` | Папка игры (для локальных файлов) |

### Лимиты памяти

```
limits {
    maxPixelsPerFrame = 4000000   # Макс. пикселей в кадре (≈2000×2000)
    maxFrames         = 100       # Макс. кадров в анимации
    maxBytesPerCape   = 67108864  # Макс. байт на один плащ (64 МБ)
    maxBytesTotal     = 134217728 # Суммарно на все плащи (128 МБ)
}
```

При превышении лимитов применяется многоступенчатая деградация: сжатие → прореживание кадров → удаление из кэша. FPS не просаживается.

## Команды

Все команды клиентские — работают в одиночке и на сервере без прав.

| Команда | Действие |
|---|---|
| `/cp reload` | Перечитать конфиг и перезагрузить плащи |
| `/cp list` | Список закэшированных плащей и объём памяти |
| `/cp status` | Версия, число провайдеров/плащей, память |
| `/cp clear` | Очистить кэш плащей |

## Форматы

| Формат | Анимация | Прозрачность | Примечание |
|---|---|---|---|
| PNG | — | tRNS | Статичные плащи |
| APNG | да | да | Полная композиция кадров |
| GIF | да | да | LZW, интерлейс, NETSCAPE2.0 |
| WebP (lossless) | да | да | VP8L, ANMF-анимация |

Формат определяется автоматически по сигнатуре файла — расширение не важно.

## Производительность

- Фоновая загрузка: декодирование идёт на отдельном потоке, рендер никогда не блокируется
- GPU-текстуры обновляются ~10 раз/сек, а не на каждый кадр
- UMA-память под контролем: LRU-кэш с жёсткими лимитами
- Адаптивная деградация: слишком большие плащи сжимаются, не убивая FPS
