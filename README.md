# CapeCraft

Кастомные анимированные плащи для Minecraft **1.21.1 / 1.21.4 / 1.21.8 / 1.21.10 / 1.21.11 / 26.2** (Fabric). Поддержка PNG, APNG, GIF и WebP — включая полную анимацию с прозрачностью и бесконечным циклом. Все версии собираются из одного репозитория.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/) для своей версии Minecraft
2. Скопируй `capecraft-1.0.0-<версия>.jar` из [Releases](https://github.com/i3667563-dot/CapeCraft-Releases/releases) в папку `mods/`
3. Запусти игру — мод загрузится автоматически

**Требования:** Fabric API, Fabric Language Kotlin (оба входят в стандартные сборки Fabric).

## Сборка из исходников

Версия выбирается флагом `-Pmc` (дефолт — 26.2):

```bash
./gradlew build -Pmc=1.21.1      # и 1.21.4, 1.21.8, 1.21.10, 1.21.11 (yarn, JDK 21)
./gradlew build -Pmc=26.2        # сборка под Minecraft 26.2 (необфусц., JDK 26)
```

## Конфигурация

При первом запуске создаётся `config/capecraft.kn`. Формат — **`.kn`** (надмножество `.crn`), построенный на ядре **Cren** (`dev.ggtv.kjen`) с расширением **Koren** (`dev.ggtv.koren`) для мировых контекстов. Минималистичный и читаемый.

### Язык `.kn`

`.kn` — надмножество `.crn`. Вся валидная `.crn`-синтаксис совместима с `.kn`, но `.kn` добавляет:

- **Вызовы функций** через скобки: `clamp(x, 0, 100)` → `VFunc`
- **Мировой контекст** (`WorldContext`) для условий в `when { ... }`

Любой валидный `.crn` парсится идентично `.kn`.

#### Токены

| Токен | Символ | Описание |
|-------|--------|----------|
| `Word` | `ключ`, `my-key`, `привет` | Идентификаторы (буквы, цифры, `_`, `-`) |
| `Str` | `"text"`, `"line\nescape"` | Строки с `"`, `\\`, `\n`, `\t` |
| `Int` | `4000000`, `-5` | Целые числа |
| `Float` | `3.14`, `-0.5` | Дробные (только если за точкой идёт цифра) |
| `Bool` | `true`, `false` | Булевы |
| `Assign` | `=` | Присваивание |
| `Colon` | `:` | Разделитель в словарях (альтернатива `=`) |
| `LBrace`/`RBrace` | `{`/`}` | Блоки |
| `LBracket`/`RBracket` | `[`/`]` | Массивы |
| `LParen`/`RParen` | `(`/`)` | Вызовы функций (только `.kn`) |
| `Comma` | `,` | Разделитель элементов |
| `Dot` | `.` | Точка в путях |
| `Comment` | `# текст` | Комментарий до конца строки |
| `Newline` | `\n` | Перевод строки |

#### Синтаксис записей

Запись — это `ключ = значение` или контейнер `ключ { ... }` / `ключ [ ... ]`. После ключа можно указать явный тип: `ключ str = "value"`. Допустимые типы: `str`, `int`, `float`, `bool`, `dict`, `array`, `block`, `ref`.

```
# Запись с присваиванием
name = "example"

# Запись с явным типом
count int = 42

# Блок
capeCraft {
    key = "value"
}

# Словарь (через : или =)
when: { time.period: "!day" }
```

#### Словари

```
{ key: value, key: value }
```

- Запятые **обязательны** между парами
- Ключи могут быть точечными путями: `time.period: "!day"`
- И `:` и `=` оба работают как разделитель ключ-значение

#### Массивы

```
[ item1, item2, item3 ]
```

Запятые **обязательны** между элементами. Элементы могут быть любыми значениями.

#### Пути (ссылки)

- Абсолютный путь: `server.host` или `.shared.host` (относительный)
- Индексированный: `server1[1]` — номер после имени
- Ссылка на значение: `server.token[1]`
- Функции: `clamp(x, 0, 100)` → `VFunc`

#### Условия (`when`)

```
when: { biome.precipitation: "snow", weather.condition: "!rain" }
```

Предикаты: `поле <оператор> значение`. Все предикаты должны выполниться (AND).

| Оператор | Пример | Описание |
|----------|--------|----------|
| `!` | `"!rain"` | Не равно |
| `>` | `">63"` | Больше |
| `>=` | `">=63"` | Больше или равно |
| `<` | `"<100"` | Меньше |
| `<=` | `"<=100"` | Меньше или равно |
| `..` | `"10..20"` | Диапазон включительно |
| без оператора | `"snowy"` | Равенство |

Доступные корни мира: `biome` (id/precipitation), `weather` (condition), `time` (period), `dimension` (type), `location` (y). Семантические алиасы: `when biome: "snowy"` → `precipitation == "snow"`.

### Провайдеры

Провайдеры — источники плащей. Проверяются по порядку: первый успешный отдаёт плащ. Без условия — default/fallback.

Встроенные типы: `url`, `file`, `json`. Аддон-провайдеры регистрируются через API (`CapeApiHolder`).

```
capeCraft {
    providers [
        # Прямая ссылка на картинку
        { name = "example", type = "url", url = "https://example.com/capes/{username}.png" }

        # JSON-API: извлекаем URL из ответа по пути
        { name = "api", type = "json", url = "https://api.example.com/cape?u={username}", extract = "$.data.cape_url" }

        # Локальный файл
        { name = "local", type = "file", path = "{root}/capes/{uuid}.png" }

        # Условный провайдер: снег в снежных биомах
        { name = "snow", type = "url", url = ".../snow.png",
          when: { biome.precipitation: "snow" }, priority = 20 }
    ]
}
```

### Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `{username}` | Имя профиля игрока |
| `{uuid}` | UUID без дефисов (нижний регистр) |
| `{name}` | Имя провайдера |
| `{root}` | Папка игры (для локальных файлов) |

### Лимиты памяти

```
limits {
    maxPixelsPerFrame = 4000000   # Макс. пикселей в кадре (≈2000×2000)
    maxFrames         = 100       # Макс. кадров в анимации
    maxBytesPerCape   = 67108864  # Макс. байт на один плащ (64 МБ)
    maxBytesTotal     = 134217728 # Суммарно на все плащи (128 МБ)
}
```

При превышении лимитов применяется многоступенчатая деградация: сжатие area-average → прореживание кадров → удаление из LRU-кэша. FPS не просаживается.

Константы: `BYTES_PER_PIXEL = 4`, `FRAME_TARGET_PIXELS = 1_000_000`, `MIN_DIM = 8`.

### Команды

Все команды клиентские — работают в одиночке и на сервере без прав.

| Команда | Действие |
|---|---|
| `/cp reload` | Перечитать конфиг и перезагрузить плащи |
| `/cp list` | Список закэшированных плащей и объём памяти |
| `/cp status` | Версия, число провайдеров/плащей, память |
| `/cp clear` | Очистить кэш плащей |

### Форматы

| Формат | Анимация | Прозрачность | Примечание |
|---|---|---|---|
| PNG | — | tRNS | Статичные плащи |
| APNG | да | да | Полная композиция кадров |
| GIF | да | да | LZW, интерлейс, NETSCAPE2.0 |
| WebP (lossless) | да | да | VP8L, ANMF-анимация |

Формат определяется автоматически по сигнатуре файла — расширение не важно.

## Производительность

- Фоновая загрузка: декодирование идёт на отдельном потоке, рендер никогда не блокируется
- GPU-текстуры обновляются ~10 раз/сек, а не на каждый кадр
- UMA-память под контролем: LRU-кэш с жёсткими лимитами
- Адаптивная деградация: слишком большие плащи сжимаются, не убивая FPS
