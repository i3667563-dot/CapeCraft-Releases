## CapeCraft 1.1.2

Кастомные анимированные плащи для Minecraft 1.21.1 / 1.21.4 / 1.21.8 / 1.21.10 / 1.21.11 / 26.2

### Установка

1. Установи [Fabric Loader](https://fabricmc.net/) для своей версии Minecraft
2. Скопируй нужный `capecraft-1.1.2-<версия>.jar` в папку `mods`
3. Запусти игру

### Что нового

**1.1.2 — про то, что мод не должен молчать о своей поломке.**

Единственное функциональное изменение релиза: `CAPECRAFT_CONFIG`, указывающий на
недоступный файл, больше не выключает мод целиком.

Ситуация простая и неприятная: переменная задана, файла по ней нет. Опечатка в
пути, том не смонтирован, конфиг переехал на другую машину, ключ из лаунчера
остался с прошлого сервера. Раньше мод в этом случае писал одну строку в лог и
уходил, оставляя **ноль провайдеров**: плащей не видно, в чате ничего не
сказано, `/cp status` ничего подозрительного не показывает. Разгадать можно
было только по логу — если человек туда заглянет.

Теперь такой файл не заменяет конфиг, а только сообщает о себе. Мод читает
обычный `config/capecraft.kn` (либо legacy `.crn`), плащи работают, а причина
уходит в лог **и** в чат:

```
> /cp status
CapeCraft 1.1.2
Игрок: ggshnikk
Конфиг: /home/gg/.minecraft/config/capecraft.kn
  ВНИМАНИЕ: /opt/capes/prod.kn: файл не найден или не читается; читаю обычный конфиг /home/gg/.minecraft/config/capecraft.kn
Провайдеров: 4 (локальный конфиг)
```

`/cp reload` теперь тоже печатает настоящий путь конфига и дописывает причину
отката строкой `ВНИМАНИЕ:`. Раньше он показывал `config/capecraft.kn` всегда —
даже когда читал файл из окружения, — то есть отличить свой конфиг от чужого
было нечем.

### Проверено

- Шесть версий: BUILD SUCCESSFUL, полный набор тестов на каждой, 0 failures.
- Новые тесты на выбор файла покрывают пять случаев: переменная не задана,
  файл есть, файл недоступен при живом `.kn`, файл недоступен при живом legacy
  `.crn`, файл недоступен и конфигов нет вовсе. Проверка мутациями: возврат
  прежнего поведения (отказ вместо отката) роняет три теста — то есть тесты
  действительно смотрят на откат, а не просто зелёные.
- Инвариант из 1.0.0 на месте и не сломан: существующий конфиг по-прежнему
  никогда не перезаписывается, а тесты на это по-прежнему зелёные.
