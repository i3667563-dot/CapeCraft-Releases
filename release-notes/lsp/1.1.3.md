# capecraft-lsp 1.1.3

Верный конфиг перестал выглядеть проблемным, а ошибки перестали дублироваться.

## Что исправлено

**Две ошибки на одну причину.** Живой пример: аддон вынесли из `mods`, и на строке
провайдера появлялось «`«seed» не подходит. Допустимо: url, json, file» и следом
«`неизвестный ключ «gray». Доступны: name, type, priority, when, self, if, url,
path и ещё 1`». Второе сообщение — враньё: список «доступных» состоял из
встроенных ключей, а `gray` — ключ типа, о котором сервер в этот момент ничего
не знал. Теперь про ключи неизвестного типа молчат, и остаётся одна ошибка с
причиной. Опечатку рядом с встроенным типом по-прежнему ловит.

**Двенадцать «багов» на верном файле.** К каждому полю `when` прилагалось
пояснение из hover — как диагностика. Конфиг на 26 строк с одиннадцатью верными
условиями давал двенадцать проблем в статусной строке, и число переставало что-либо
значить. Пояснение осталось в hover, где оно и было нужно; диагностикой уходят
только настоящие ошибки: неизвестный корень, неизвестное поле, значение не из
списка, сравнение вместо значения.

## Что поправлено в словаре `when`

Ничего не добавлено — наоборот, убрано то, чего в моде не было. Сервер 1.1.0–1.1.2
был собран из ветки, где сегодня появились семь корней `when` (`fire`, `hand`,
`food`, `xp`, `effect`, `effect_amplifier`, `effect_duration`) и контекст игрока
для аддонов. В мод это не попало ни в один релиз, но редактор успешно предлагал
несуществующий синтаксис и врал про конфиг, который мод отверг бы при загрузке.

Теперь словарь `when` сервера совпадает с модом: `biome`, `weather`, `time`,
`dimension`, `location`, `armor`, `health`, `state`. Корни, которых нет в
установленном моде, сервер не предлагает и помечает как ошибку — как и должен.

## Проверено

- 1093 теста сервера и мода, падений нет;
- прогон настоящего `capecraft.kn` из экземпляра игры: с аддоном на месте — ноль
  диагностик; без аддона — ровно одна, на `type`;
- проверка на прежнем словаре `when` падает: сервер больше не знает несуществующих
  корней;
- сквозной прогон настоящего `capecraft-lsp.jar` как отдельного процесса.
