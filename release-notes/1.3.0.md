## CapeCraft 1.3.0

Кастомные анимированные плащи для Minecraft 1.21.1 / 1.21.4 / 1.21.8 / 1.21.10 / 1.21.11 / 26.2

Синхронизация осталась на протоколе **v4**. Формат пакетов не менялся: обновляться
можно по одному клиенту, сервер тянет любую из этих версий.

### Аддонские условия `when`

Аддон теперь умеет объявлять свои корни `when`, и мод перестаёт держать список
состояний сущности у себя.

```kn
when = { fire: "true" }
when = { fire.ticks: ">100" }
```

Первая строка работает, если стоит аддон
[CapeCraft Fire](https://github.com/i3667563-dot/CapeCraft-Releases/releases)
(мод 1.3.0 или новее). Вторая — то же самое плюс счётчик тиков горения.

Что важно знать:

- **Это условие никогда не передаётся другим игрокам.** Состояние сущности
  известно только тебе, поэтому условие помечено локальным и по сети не
  объявляется. Под соседом такой плащ не появится — так и задумано.
- **Встроенные корни на месте:** `weather`, `time`, `dimension`, `location`,
  `armor`, `health`, `state`, `biome`, плейсхолдеры `${…}`. Аддон не может
  занять встроенное имя: если в `capecraft-addon.kn` объявить `weather`,
  сработает встроенный, а в stderr LSP появится строка про конфликт.
- **Редактор знает про аддонские корни** — из `capecraft-addon.kn` в jar'е
  аддона: корень появляется в автодополнении, поля в подсказке по условию,
  значения в подсказке по полю. Подсказки обновляются сами после установки
  аддона, открывать файл заново не нужно.

`API version` мода поднят до **2**: это версия `api.whenConditions` и секции
`conditions` в дескрипторе. Аддон, собранный против 1.2.x, новых корней не
принесёт и объявит их молча — поэтому в дескрипторе аддона пишется
`apiVersion = 2`, и сверку ставит тест аддона, а не человек.

### Установка

1. Мод: `capecraft-1.3.0-<mc>.jar` — заменить старый, старый удалить.
2. Аддон (по желанию): `capecraft-fire-1.0.0.jar` в ту же папку `mods`.

Синхронизация: сервер и клиенты могут быть разных версий, протокол не менялся.
Аддон — только на тех клиентах, где его плащ нужен: у остальных игроков
`fire` просто не совпадёт, и это не ошибка.

Редактор: сервер LSP обновляется отдельно, `capecraft-lsp 1.1.4`.
